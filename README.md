# StemVault (`stem-store`)
StemVault is a modern, full-stack e-commerce marketplace built for music producers, creators, and artists to preview, favorite, purchase, and download high-quality audio stems. 

This repository houses both the consumer-facing frontend and the robust server-side REST API.
## 🚀 Key Features
**Dynamic Storefront**: Responsive catalog exploration with multi-genre search, sorting, and tag-based filtering.
